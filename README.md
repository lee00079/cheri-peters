# Grace in the Darkness — Cheri Peters NZ Tour 2026

Landing page for **Grace in the Darkness: A Five-Part Journey from Trauma to Hope**, a free community event with international speaker Cheri Peters running in Mount Maunganui, Hamilton, and North Harbour, October–November 2026.

Static site, no build step. Deployed via GitHub Pages at [cheripeters.com](https://cheripeters.com).

## Structure

- `index.html` / `styles.css` — the production site
- `assets/cheri.jpg` — hero portrait
- `CNAME` — custom domain config for GitHub Pages
- `design_handoff_grace_in_the_darkness/` — original design reference bundle (prototype HTML, screenshots, full spec in its own README) that `index.html`/`styles.css` were built from
